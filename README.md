# Rubik's Cube First Pair Solver

## Overview

A C++ project exploring optimisation techniques for generating efficient solutions for the first pair stage of CFOP Rubik's Cube solving.

## Goals

- Represent cube states efficiently
- Generate valid move sequences
- Explore heuristic search approaches
- Analyse solution efficiency

## Current Progress

- Cube state representation implemented
- Move generation implemented
- Basic search framework in development

## Technologies

- C++
- Search algorithms
- Heuristic optimisation

## Future Improvements

- Improve search efficiency
- Add execution advice
- Expand solving stages
